# Lab 01 Basic Operations and Control Statements

Contains 30 standalone Python solutions and the original question PDF.

## Run a solution

Open a terminal in this folder and run:
```bash
python Q01_*.py
```

Each program asks for input where appropriate. Python 3 is required.
