MCA101P-AS06 — Python Programming Lab: Set Operations

This ZIP contains 30 separate Python source files for the 30 tasks in Lab Sheet-06.

How to run:
1. Extract the ZIP file.
2. Open a terminal/command prompt in the extracted folder.
3. Run a program with: python Q1_set_creation.py
   (Use python3 instead of python if required by your system.)

Notes:
- Python 3.x is required.
- Some programs ask for input; follow the prompts.
- Set display order can vary because sets are unordered.
- Q27 compares sorted characters because sets alone do not preserve repeated-letter counts,
  which are important when checking anagrams.
