# Python Lab Sheet-06 — Set Operations

**Course:** Python Programming Lab  
**Topic:** Set Operations  
**Programs:** 30

## Contents
This folder contains 30 separate Python 3 programs, one for each question in Lab Sheet-06.

## How to run
1. Install Python 3.
2. Open this folder in VS Code, IDLE, or another Python editor.
3. Open the required `.py` file.
4. Run it. For input-based programs, type the requested values in the terminal.

Example:
```bash
python Q01_create_and_display_a_set.py
```

## Notes
- Each program includes a short comment describing its task.
- Sets are unordered, so the order of displayed elements may differ between runs.
- Some questions use fixed example sets to demonstrate the operation; questions that naturally require user input ask for it.
- Q19 uses `frozenset` for subsets because ordinary sets cannot contain other mutable sets.
- Q27 checks both the character set and character frequencies, so repeated letters are handled correctly.

## Submission report
All 30 programs were prepared using Python 3 set operations. The programs demonstrate set creation, adding and removing elements, membership, length, iteration, union, intersection, difference, symmetric difference, subset/superset, disjointness, power set, Cartesian product, duplicate handling, string operations, frozenset, and min/max. Run each file in Python to view its output.
