# Lab Sheet-06 Report: Python Set Operations

## Objective
To understand Python sets and perform basic and advanced set operations.

## Implementation
A total of 30 individual Python 3 source files have been created. Each file corresponds to one program in the supplied lab sheet. The programs use built-in set methods and operators wherever appropriate.

## Topics Covered
1. Set creation and display
2. Different data types in a set
3. Adding one or multiple elements
4. Removing elements with `remove()` and `discard()`
5. Clearing, membership, length, and iteration
6. Union, intersection, difference, and symmetric difference
7. Subset, superset, and disjoint checks
8. Difference update, power set, and Cartesian product
9. Distinct and duplicate list elements
10. String character sets, common letters, unique words, and anagrams
11. Frozenset and minimum/maximum values
12. Combined basic set operations

## Result
The programs are written as separate `.py` files and are ready to run with Python 3. Since sets are unordered, the display order can vary. For final submission, run each program in the local Python environment and verify the output for the chosen inputs.
